개인정보처리방침

시행일: 2026-10-04

1. 누가 쓰는가

nine-pipe는 앱 소유자가 자기 Google 계정에만 쓰는 개인용 도구입니다. 다른 사용자의 계정에는 접근하지 않습니다.

2. 어떤 정보를 쓰는가

Google 계정의 Gmail 메일(제목, 보낸 사람, 본문)을 읽기 전용 권한(gmail.readonly)으로 읽습니다. 메일을 보내거나 수정·삭제하지 않습니다.

3. 어떻게 쓰는가

읽은 메일은 소유자 본인의 컴퓨터에서 알림 목록과 요약을 만드는 데만 씁니다. 제3자에게 판매·공유·전송하지 않으며 광고에 쓰지 않습니다.

4. 보관과 삭제

정리된 내용은 소유자 본인의 컴퓨터와 개인 백업 장치에만 저장됩니다. Google 계정 설정의 타사 앱 액세스에서 언제든 권한을 해제할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

nine-pipe의 Google API 정보 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
